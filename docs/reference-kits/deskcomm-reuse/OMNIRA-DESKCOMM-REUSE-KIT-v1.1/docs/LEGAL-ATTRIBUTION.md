
## Regra

Ao copiar ou adaptar código ou parte substancial:

1. manter um `THIRD_PARTY_NOTICES.md` no OMNIRA;
2. incluir o aviso de copyright/licença aplicável;
3. registrar os arquivos de origem;
4. registrar o commit de origem.

## Template

```text
## DeskcommCRM

Source:
https://github.com/melgarafael/DeskcommCRM

License:
MIT

Copyright:
Copyright (c) 2026 Rafael Melgaço

Used/adapted:
- <OMNIRA path> ← <Deskcomm path> @ <commit>
```

## Não fazer

- remover attribution exigida;
- afirmar autoria original do OMNIRA sobre código copiado;
- copiar assets de marca sem avaliar necessidade/licença;
- copiar secrets, `.env`, dumps, evidências ou dados de produção.
