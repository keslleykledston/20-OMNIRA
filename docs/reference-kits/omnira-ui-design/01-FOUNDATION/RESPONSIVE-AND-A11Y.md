# Responsividade e acessibilidade

## Breakpoints funcionais

- Desktop: ≥1280 px.
- Tablet: 768–1279 px.
- Mobile: <768 px.

## Inbox

- desktop: lista + chat + contexto;
- tablet: lista + chat; contexto em Sheet;
- mobile: lista → chat; contexto/ticket em Sheet full-height.

## Tabelas

Desktop: tabela completa. Tablet: esconder colunas secundárias ou horizontal scroll controlado. Mobile: card rows ou lista densa; não reduzir texto a ponto ilegível.

## WCAG AA

- focus visible;
- keyboard navigation;
- `aria-label` em icon buttons;
- label real em inputs;
- não depender apenas de cor para status;
- target mínimo aproximado 40–44 px em touch;
- modals/sheets com focus trap e Escape;
- contraste de texto secundário validado.
