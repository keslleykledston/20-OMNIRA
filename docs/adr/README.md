# ADRs

ADRs registram decisões:
- difíceis/caras de reverter;
- surpreendentes sem contexto;
- resultantes de trade-off real.

Formato:
- Status
- Contexto
- Decisão
- Consequências
- Alternativas

Não criar ADR para escolha trivial ou facilmente reversível.
