2. **API Base**: Vite proxy redireciona `/api` para `http://localhost:8080/api`
3. **Token**: Automaticamente incluído em todas as requisições
4. **Types**: TypeScript strict mode ativo
5. **Styling**: TailwindCSS com JIT mode (não precisa importar classes)
