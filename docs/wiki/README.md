## Sobre esta documentação

- As telas são **capturas do sistema real com dados inventados** ("Empresa Exemplo", "Ana Souza"): nenhum dado de cliente aparece.
- Cada passo foi conferido contra o produto. O que **ainda não existe** está no FAQ, e o que falta documentar está no [plano](PLANO-DA-DOCUMENTACAO.md).
- Achou algo diferente do que viu na tela? Avise a equipe do OMNIRA: a doc é corrigida junto com o produto.
