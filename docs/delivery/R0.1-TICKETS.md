# Tickets — R0.1 Tenant Foundation

## T01 — Bootstrap Go repo
**Entrega:** API e worker compilam; config e graceful shutdown.

Aceite:
- `go test ./...`;
- API inicia;
- `/internal/health/live`.

## T02 — Local infrastructure
**Entrega:** compose com Postgres + NATS + OTel.

Aceite:
- um comando sobe dependências;
- volumes persistentes;
- healthchecks.

## T03 — Migration framework + schema base
**Entrega:** migrations de users, tenants, memberships, roles, permissions, audit, outbox.

Aceite:
- banco vazio -> latest;
- rollback testado onde seguro;
- constraints/FKs/índices.

## T04 — Authentication adapter
**Entrega:** middleware valida JWT/OIDC e produz `Principal`.

Aceite:
- token válido autentica;
- inválido/expirado falha;
- módulos não parseiam JWT diretamente.

## T05 — Tenant + Membership domain
**Entrega:** entidades, repositories e application services.

Aceite:
- memberships ativas/inativas;
- roles básicos;
- invariantes testadas.

## T06 — Authorization + TenantContext
**Entrega:** autorização backend e construção de TenantContext.

Aceite:
- usuário autorizado entra;
- não autorizado recebe resposta segura;
- `tenant_id` do request não concede autoridade.

## T07 — RLS / persistence isolation
**Entrega:** policies e mecanismo de context por transação.

Aceite:
- testes A/B em PostgreSQL real;
- read/write cruzado bloqueado.

## T08 — Tenant API
**Entrega:** `/me`, tenant list/detail, membership list/manage.

Aceite:
- OpenAPI;
- pagination onde aplicável;
- error format padrão;
- authorization completa.

## T09 — Audit
**Entrega:** audit events para login/context/admin/membership.

Aceite:
- actor/tenant/correlation;
- metadata sem segredo/PII desnecessária;
- leitura protegida.

## T10 — Outbox + NATS publisher
**Entrega:** tabela/outbox dispatcher + JetStream publish.

Aceite:
- evento não se perde entre commit e publish;
- retry;
- métricas;
- idempotência de publish/consumer definida.

## T11 — OpenTelemetry baseline
**Entrega:** traces, metrics e structured logs.

Aceite:
- trace HTTP -> DB;
- correlation_id;
- dashboard mínimo API/outbox;
- sem labels explosivas.

## T12 — Isolation test harness
**Entrega:** suite adversarial reutilizável.

Casos:
- A vs B;
- UUID conhecido;
- membership revogada;
- list/search;
- tentativa de role escalation.

## T13 — Backup/restore dev drill
**Entrega:** primeiro restore documentado.

Aceite:
- backup realizado;
- ambiente limpo restaurado;
- checks de tenants/memberships/audit;
- RPO/RTO observado registrado.

## Gate R0.1

R0.1 só fecha quando T01–T13 estiverem concluídos e isolation suite + restore drill estiverem verdes.
