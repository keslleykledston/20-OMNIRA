## Implementado

### 1. PostgreSQL Migration (Phase 1)
- **File**: `migrations/000020_create_channel_credentials.{up,down}.sql`
- **Schema**: channel_credentials table (tenant-owned, RLS+FORCE)
  - Columns: id UUID, connection_id UUID, tenant_id UUID, nonce BYTEA, ciphertext BYTEA
  - Indexes: connection_id, tenant_id
  - Foreign keys: channel_connections, tenants (ON DELETE CASCADE)
  - RLS policy: FORCE enabled, tenant_id must match current_setting

### 2. AES-256-GCM Cipher (Phase 2)
- **File**: `internal/channels/adapters/crypto/cipher.go`
- **Features**:
  - Key: OMNIRA_CREDENTIALS_KEY (base64, 32 bytes from env)
  - Encrypt: generates fresh 12-byte nonce per call, never reused
  - Decrypt: extracts nonce from ciphertext prefix, validates auth tag
  - Error handling: fails fast if key missing/invalid (never fallback)
- **Tests**: `cipher_test.go` (8 unit tests)
  - Roundtrip, nonce uniqueness, wrong key, tampered data, key validation

### 3. CredentialStore PostgreSQL Adapter (Phase 3)
- **File**: `internal/channels/adapters/postgres/credential_store.go`
- **Implements**: ports.CredentialStore interface
  - Store: JSON serialize → AES-256-GCM encrypt → persist [nonce + ciphertext] → return UUID
  - Resolve: query (RLS) → decrypt → return Credential (server-side only)
  - Rotate: replace credential, maintain secretRef UUID
- **Security**:
  - TenantContext required; fails if missing or empty
  - RLS policy enforced; defense-in-depth with explicit WHERE tenant_id
  - Credential never returned to non-server callers

### 4. ChannelConnectionRepository PostgreSQL Adapter (Phase 4)
- **File**: `internal/channels/adapters/postgres/connection_repository.go`
- **Implements**: ports.ChannelConnectionRepository interface
  - Store: persist ChannelConnection (RLS enforced)
  - FindByID: retrieve by ID (RLS)
  - **FindByExternalNumberID**: webhook-safe resolution (NEVER trust payload)
    - Source of truth: provider + externalNumberID → TenantID
    - Critical for webhook inbound safety (bug #236 pattern prevented)
  - FindByTenant: list all connections for tenant
  - Update: status, capabilities, risk acknowledgement
  - Capabilities stored as PostgreSQL array; scanners convert

## Security

### Credentials

✅ **NATS**: no token
- CredentialStore.Resolve() only callable server-side
- Never serialized to NATS message

✅ **Logs**: no token
- Credential.String() returns "Credential{N campo(s) redigido(s)}"
- Credential.GoString() also redacted (covers %v, %#v)

✅ **API Response**: no token
- ChannelConnection returns SecretRef (UUID), not Credential
- Resolve() not exposed via HTTP handler

✅ **Frontend**: no token
- Credential never transmitted to client
- Only SecretRef (opaque UUID) visible externally

✅ **Worker**: resolves server-side
- Worker receives: tenant_id, channel_connection_id, operation/request id
- Worker calls CredentialStore.Resolve(ctx, secretRef) → Credential in RAM
- Used immediately; never serialized/logged/returned

### Secrets

✅ **SecretRef opaque**: UUID format
- No ciphertext, plaintext, or hash visible
- Credential only accessible via CredentialStore.Resolve(secretRef)
- Rotating token doesn't change SecretRef (trocável design)

✅ **TenantID mandatory**: prevents bug #236 pattern
- Domain enforces via NewChannelConnection validation (D2)
- Store/Resolve rejects nil TenantID
- TenantContext required in all queries

✅ **Nonce never reused**: fresh per Encrypt
- crypto/rand generates 12 bytes per call
- Test validates 1000 calls → 1000 unique nonces
- AES-256-GCM security depends on unique nonce per key

✅ **RLS + FORCE enforcement**:
- channel_credentials table protected by RLS policy FORCE
- channel_connections table (D0+) protected
- Even superuser cannot bypass

### Boot Security

✅ **OMNIRA_CREDENTIALS_KEY missing/invalid = fail fast**
- NewAES256GCMCipher() returns error if:
  - Env var not set
  - Base64 invalid
  - Size not 32 bytes
- Application must fail on startup; never operates in degraded mode
