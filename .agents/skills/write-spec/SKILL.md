# Skill: write-spec

## Entrada
Conversa/decisões já suficientemente resolvidas.

## Saída
Spec em `docs/product/` ou `docs/specs/` contendo:
- problema;
- usuários;
- escopo;
- não escopo;
- regras;
- jornadas;
- critérios de aceite;
- métricas;
- riscos;
- dependências;
- decisões abertas.

Não inventar decisão ainda aberta; marcar explicitamente.
