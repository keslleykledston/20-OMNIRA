# Skill: slice-tickets

Transforme a spec em tickets verticais demonstráveis.

Cada ticket contém:
- objetivo;
- dependências;
- arquivos/módulos prováveis;
- critérios de aceite;
- testes;
- observabilidade;
- riscos de tenancy;
- definição de pronto.

Preferir slices que cruzem UI/API/persistência de forma fina a camadas horizontais enormes.
